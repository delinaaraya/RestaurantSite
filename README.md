# RestaurantSite
# Uncle's Business Website (Draft Mockup)

## Overview
This repository contains an early website mockup created for a family business. The purpose of this project was not to build the final website, but to provide a visual prototype that could be reviewed before full development began.

Rather than presenting wireframes or technical diagrams, I chose to create a simple functional website using HTML and CSS. This allowed the business owner, who does not have a technical background, to better visualize the site's structure, layout, and overall aesthetic before investing time in a complete build.

## Current Status
This project is a draft and is not intended to represent the finished website. Content, styling, functionality, and design elements are subject to change based on feedback and future development.

## Included Pages
* Home Page (index.html)
* Menu Page (menu.html)
* Our Story Page (ourstory.html)
* Gallery Page (gallery.html)

## Technologies Used
* HTML5
* CSS3

## Purpose
The goal of this prototype was to establish the overall direction and feel of the website while creating an accessible way for a non-technical stakeholder to review and provide feedback on the proposed design.
